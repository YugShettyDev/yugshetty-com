About Vesper

Vesper is a task management web application built around a simple idea: your tasks should live in a system that helps you actually organize your work, not just store a list of things to do.

I built Vesper as a real, usable application from the ground up, rather than as a static concept or UI experiment. It includes authenticated accounts, persistent data, and synchronization across devices, allowing the same workspace to remain accessible whether you're using Vesper on a desktop or mobile device.

The project is also an experiment in how far a personal task-management application can go beyond the traditional todo list. The current version establishes the foundation; future iterations can build more intelligence around how people define goals, break them down, plan their time, and execute them.

Vesper is currently deployed and actively usable.

Built by Yug Shetty.

Key Features

Intentional Task Organization

A structured system designed to help you actively organize your priorities rather than simply maintaining an overwhelming, static to-do list.

Custom Multi-View Calendar

Custom-built Vanilla JavaScript calendar featuring Day, 3-Day, Week, and Month views for intuitive scheduling and time allocation.

Auth & Multi-Device Sync

Authenticated user accounts via Supabase Auth (Email & Google OAuth) with PostgreSQL Realtime synchronization across desktop and mobile.

Row Level Security (RLS)

Granular database-level security policies ensuring complete isolation and privacy for your personal workspace and task records.

Native ES Modules & Zero-Build

Lightweight zero-build architecture running directly in modern browsers without heavy compilation pipelines or framework overhead.

Warm Editorial Aesthetics

Crafted with Fraunces serif typography, soft linen textures, honey amber ambient glows, and terracotta accents that feel warm and human.
